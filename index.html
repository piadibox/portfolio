Tracker combattimento D&D

Software per gestire il combattimento in Dungeons & Dragons, con gestione di iniziativa, punti ferita e condizioni dei personaggi. Programmato in Python con interfaccia grafica Tkinter, progettato per Dungeon Master che vogliono semplificare la gestione del combattimento.

project_02

Web App Pentagramma

Applicazion web per la gestione di una scuola di musica, con gestione di studenti, insegnanti e lezioni. Realizzata con Next.js e Tailwind CSS, con autenticazione e autorizzazione degli utenti, database PostgreSQL e API REST per la gestione dei dati. Prisma ORM per la gestione del database e NextAuth.js per l'autenticazione.

Next.js JavaScript Tailwind CSS PostgreSQL Prisma NextAuth.js

project_03

Homelab ProxmoxVE

Homelab con ProxmoxVE, con macchine virtuali e container per testare e sperimentare con diversi sistemi operativi, software e penetration testing. Contiene un server di minecraft, un adblocker con Pi-hole, un server cloud personale con Nextcloud, un servizio di streaming multimediale con Plex. Per il penetration testing, ho configurato una VM con Metasploitable2 e un container con DVWA (Damn Vulnerable Web Application) per testare vulnerabilità web.

ProxmoxVE Linux Networking
